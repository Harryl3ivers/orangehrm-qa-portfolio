# OrangeHRM QA Test Plan

## Application

OrangeHRM Employee Management System

## Objective

Validate the functionality, reliability and usability of key HR workflows.

## Scope

Testing will cover:

- Authentication
- Employee management
- Employee search
- User permissions
- Leave management

## Testing Types

- Functional testing
- Regression testing
- Negative testing
- Exploratory testing
- UI automation testing
- API testing

## Tools

- Playwright
- Pytest
- Postman
- GitHub Actions
